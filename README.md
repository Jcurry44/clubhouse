# Clubhouse

Joe's one-app home for golf, training, bourbon and Buffalo sports. A static, installable PWA:
vanilla ES modules, no build step, no accounts, no backend. Everything lives on the phone
(IndexedDB + the vendored apps' localStorage), with one-tap backups.

## Run it locally

```sh
cd app
python -m http.server 8822        # any port; http://localhost:8822/
```

Open it at 390 × 844 (iPhone). The service worker registers on localhost too; there it serves
every same-origin file network-first, so edits show on reload and the offline cache is still exercised.

## Tests

```sh
node tests/run.mjs            # every tests/*.test.mjs (pure modules)
node tests/run.mjs backup     # just one file
node scripts/precache.mjs --check
```

Home's browser checks (first run → the three imports end to end, sample data, fixed-clock Thursday/Sunday, offline, widths) live in `../design/build/home-verify.py`.
Browser checks for the shell (routes, LOG sheet, export/import/snapshots, offline, reduced motion,
sizes, tap targets) live in `../design/build/shell-verify.py` (Playwright + headless Edge).

## Release

1. Bump `CACHE_VERSION` in `sw.js` (`clubhouse-v1-YYYY-MM-DD[letter]`).
2. `node scripts/precache.mjs` — regenerates the `SHELL` precache list from the files on disk and
   syncs `js/version.js`. The vendored apps' lists live in the `VENDORED` block of `sw.js`.
3. `node scripts/precache.mjs --check && node tests/run.mjs`.

The precache install is atomic: a single missing file fails the install (the old version keeps
serving), which is why the list is generated rather than hand-edited.

## Map

| Path | What |
|---|---|
| `index.html` | shell: icon sprite, `#view`, bottom nav, `+ LOG` button, sheets, toast |
| `js/main.js` | boot: storage check, `storage.persist()`, routes, FAB, service worker + update toast |
| `js/router.js` | hash router: mount/unmount, titles, nav highlight, scroll restore, `clubhouse:refresh` |
| `js/store.js` | IndexedDB wrapper (8 stores), settings, goals, rolling snapshots |
| `js/backup.js` | export (Web Share / download), detect, validate, preview, restore, snapshots, weekly nudge |
| `js/ui.js` | `toast()`, `confirm()` (the destructive-action sheet), sheet open/close/focus-trap/drag |
| `js/dom.js` | `h()`, `esc()`, `rich()`, `icon()`, `fmt`, `ring()`, `play()`, `spark()`, `dots7()`, `fitText()` |
| `js/dates.js` | Monday-start week math, local calendar dates, formatting |
| `js/screens/sheet.js` | the quick-log sheet (options from every pillar's `quickLog.kinds`) |
| `js/screens/backup.js`, `settings.js` | Backups and Settings screens |
| `js/pillars/*`, `js/screens/*` | pillar modules and screens (see `design/SPEC.md` §2) |
| `css/tokens.css` → `base.css` → `components.css` → `screens.css` | Direction B design system |
| `js/train/*` | Train = a read-only window onto Form: `form-import.js` (parse + validate a `form-v2` export), `model.js` (e1RM, PRs, streaks, facts), `insights.js` (Coach rules), `source.js` (the `trainSource` seam), `data.js` (IDB store `trainForm`), `import-flow.js` (preview → snapshot → save → Undo) |
| `js/pillars/home.js`, `js/screens/home.js` | Home: greeting + streak pill, rings, week strip (tap a day), Coach, Next up, streaks, recap, and the four-step **Get set up** card |
| `js/coach.js`, `js/recap.js` | Coach engine (every pillar's rules + X1 backup / X2 recap / X3 full house, ranked by priority + novelty, Home caps) and the weekly recap (§6.6; Sunday 5 pm = "This week") |
| `apps/*/clubhouse-bridge.js` | `#clubhouse-import` helper in the vendored apps (generated by `design/scripts/vendor-apps.mjs`): points at the app's own Import / Restore control; folds the return pill after a scroll; in Barrel Proof also snapshots all of Clubhouse the moment Restore or Reset everything is tapped (the cabinet is read before Barrel Proof acts) |
| `data/form-catalog.json` | Form exercise/activity names, load modes, muscle groups — copied read-only from Form by `scripts/build-form-catalog.mjs` |
| `scripts/make-form-fixture.mjs` | a synthetic `form-v2` export (never real data) for tests and browser checks |

Data safety: nothing destructive happens without the confirm sheet and an automatic snapshot first
(`backup.snapshot(label)`, newest 5 kept, restorable from Backups).
